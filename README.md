# Jogo Mário
## Descrição
Prática extraclasse com intuito de aprimorarmos nossos conhecimentos em programação e desenvolvimento, passando por toda esteira de determinar prazos e funções, documentar todo processo, desenvolver o jogo e testá-lo.  
O objetivo do jogo é controlar o Mário e pular os obstáculos que aparecem pelo caminho, evitando colisões através da interação do usuário por meio do teclado. O objetivo é permanecer o maior tempo possível sem atingir os obstáculos.
